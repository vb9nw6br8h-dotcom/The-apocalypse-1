# Zombie Co-op Multiplayer

## Run locally
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:3000 in two browser windows/devices on the same network.

## Put it online
Deploy this folder to a Node.js host that supports WebSockets (for example Render, Railway, or another Node host). Give your brother the resulting HTTPS game URL. Both players enter the same room code.

Controls: WASD, mouse, click to shoot, R to reload.
